Генератор стартового проекта Fabric. Он создаёт исходники и настройки Gradle.

Как получить настоящий JAR

  1. Создай Java-проект.
  2. Скачай его через вкладку «Экспорт».
  3. Загрузи ZIP в отдельный GitHub-репозиторий.
  4. Открой вкладку Actions и запусти сборку.
  5. Скачай готовый JAR из Artifacts после завершения сборки.
